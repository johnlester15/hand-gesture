# AR 3D Hand Gesture Realistic

Next.js camera hand gesture detector with a procedural 3D hand model. No downloaded 3D hand model is used. The hand is made from code using Three.js geometry.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

Camera detection works on localhost or HTTPS. The first camera start needs internet because MediaPipe loads its hand detector model from CDN.

## Included

- Enhanced 3D hand model
- Rounded palm, capsule fingers, knuckles, palm lines, fingernails, wrist, lighting, shadows
- Smooth finger gesture transition
- Camera hand detector
- Manual emoji gesture guide
- Responsive UI for mobile and desktop

## Gestures

Open Palm, Fist, Peace Sign, Thumbs Up, Pointing Up, OK Sign, Call Me, I Love You, Rock Sign, Number Three, Number Four, L Shape.
